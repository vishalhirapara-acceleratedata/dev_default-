# Sample React App

This is a simple React application created as a sample project.

## Getting Started

### Prerequisites
- Node.js and npm installed on your machine

### Installation

1. Clone the repository:
```bash
git clone https://github.com/vishalhirapara-acceleratedata/dev_default-.git
cd dev_default-
```

2. Install dependencies:
```bash
npm install
```

### Running the Application

Start the development server:
```bash
npm start
```

The app will open in your browser at [http://localhost:3000](http://localhost:3000)

### Building for Production

Create an optimized production build:
```bash
npm build
```

### Features

- Basic React setup with functional components
- Hooks example (useState for counter)
- Simple CSS styling
- Ready to extend and customize
